# Brandon Alley Photo Organizer

This folder contains a Google Sheets-ready photo organizer workbook.

## Files

- `Brandon_Alley_Photo_Organizer.xlsx` - import this into Google Sheets.
- `flickr-image-url-apps-script.js` - optional Apps Script function for resolving pasted Flickr page URLs into thumbnail image URLs.
- `Flickr_Intake.tsv` - generated by `npm.cmd run intake:flickr`; paste these rows into `Photo Organizer` for review.

## Google Sheets Setup

1. Upload `Brandon_Alley_Photo_Organizer.xlsx` to Google Drive.
2. Open it with Google Sheets.
3. Confirm the `Photo Organizer` sheet has these working columns:
   - `Folder (Location)`
   - `Flickr URL`
   - `Preview Image`
   - `Publish Status`
   - `Featured`
4. For newly pasted Flickr page URLs, install the Apps Script:
   - Open `Extensions > Apps Script`.
   - Paste the contents of `flickr-image-url-apps-script.js`.
   - Save.
   - Return to the sheet.

Existing seeded rows already include resolved image URLs. The `Preview Image` column uses the Google Sheets `IMAGE()` formula for every row. New rows use the `FLICKR_IMAGE_URL()` function in the `Resolved Image URL` helper column, then `Preview Image` uses `IMAGE()`. Use `Publish Status` to control publishing and `Featured` to choose whether a photo should appear in the featured/homepage set.

## Sync Workflow

1. Run Flickr intake when needed:

```powershell
npm.cmd run intake:flickr
```

2. Paste any generated rows from `Flickr_Intake.tsv` into `Photo Organizer`.
3. Review rows in Google Sheets and change `Publish Status` to `Approved` only when ready.
4. Preview local site updates:

```powershell
npm.cmd run sync:sheet
```

5. Apply changes after reviewing the dry run:

```powershell
npm.cmd run sync:sheet:apply
```

The sync helper only publishes rows marked `Approved` or `Published`. It updates known `LOCATIONS_DATA` location assignments, known `Project: ...` project assignments, `Featured` values, new photo rows, and Flickr/EXIF metadata in `photo-data.js`.
